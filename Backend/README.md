# Complete Freelance Platform Backend

## Features
- Supabase Authentication (Google, LinkedIn, GitHub)
- Email/OTP Authentication  
- Role-Based Access Control (6 roles)
- SuperAdmin with encrypted credentials
- Progressive onboarding
- CMS with versioning
- Auto-sync with Supabase

## Quick Start
```bash
npm install
cp .env.example .env
# Edit .env
npm run setup:superadmin
npm run dev
```
